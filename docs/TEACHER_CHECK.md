## 1. Запуск (около 10 минут)

Нужны Python 3.11, Git и интернет на время установки и первого скачивания модели.

macOS / Linux:

```bash
git clone https://github.com/DmiHorus/F12_Site_FAQ.git F12_Site_FAQ
cd F12_Site_FAQ
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m backend.build_index
uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Windows (PowerShell):

```powershell
git clone https://github.com/DmiHorus/F12_Site_FAQ.git F12_Site_FAQ
cd F12_Site_FAQ
py -3.11 -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m backend.build_index
uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Ожидаемо:

- `build_index` печатает `Loaded 40 FAQ items from faqs.json` и сообщение о сохранении индекса; в `data/` появляются файлы индекса;
- ключи и секреты в `.env` вписывать не нужно (кроме сценария `openai`, если он указан в таблице выше);
- `uvicorn` сообщает, что сервер запущен на `http://127.0.0.1:8000`.

Сервер оставить работать, дальнейшие команды выполнять во втором терминале с активированным окружением.

## 3. Пункт 1: бот работает

Проверка состояния:

```bash
curl http://127.0.0.1:8000/health
```

Ожидаемо: `"status":"ok"`, `"faq_count":40`, название модели и режим ответа.

Вопросы удобнее задавать на странице `http://127.0.0.1:8000/faq` или в чат-виджете. Для командной строки (macOS / Linux):

```bash
curl -s -X POST http://127.0.0.1:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Как связаться с компанией?"}'
```

| № | Вопрос | Что должно быть в ответе | Запись базы |
|---|---|---|---|
| 1 | Как связаться с компанией? | `hello@mnwhl.ru` | faq-002 |
| 2 | Что такое ГОРИЗОНТ / 01? | электронная экспедиция; маршрутизация обращений и подготовка ответов | faq-013 |
| 3 | Какая точность маршрутизации получилась на пилоте? | 76%; менее 1 минуты на обращение; до 350 обращений в час | faq-015 |
| 4 | Кто запишет совещание и разнесёт поручения? | ИИ-секретарь: поручения, ответственные, сроки | faq-028 |
| 5 | Чем заменить Zabbix и RabbitMQ? | система мониторинга и диспетчер очередей | faq-034 |
| 6 | Насколько снизился брак на производстве? | с 1,3% до 0,8% | faq-037 |
| 7 | Как скрыть персональные данные перед отправкой в нейросеть? | сервис маскирования | faq-023 |
| 8 | Ответ гражданину уходит без проверки человеком? | нет; подпись и отправка остаются за исполнителем | faq-012 |

В ответе сервера поле `found` равно `true`, в `context` первая запись имеет указанный id.

**Отвечает только по данным компании.** Вопросы вне базы:

| Вопрос | Ожидаемо |
|---|---|
| Какая сегодня погода в Москве? | `found: false`; ассистент сообщает, что ответа в базе знаний нет, и предлагает написать на `hello@mnwhl.ru` |
| Как оформить возврат товара? | то же |
| Сколько стоит внедрение Горизонта? | ответ не содержит ни одной суммы: цен в базе нет |

**Память диалога.** Один и тот же второй вопрос даёт разные ответы в зависимости от первого. Проверять в чат-виджете; после первого диалога обновить страницу в новой вкладке или передать другой `session_id`.

| Диалог | Реплика 1 | Реплика 2 | Ожидаемо во втором ответе |
|---|---|---|---|
| А | Что такое ГОРИЗОНТ / 01? | А какие результаты? | 76% верной маршрутизации (faq-015) |
| Б | Какие ИИ-решения есть для промышленных предприятий? | А какие результаты? | брак с 1,3% до 0,8% (faq-037) |

**Модель работает локально.** Остановить сервер, отключить интернет, запустить `uvicorn` снова и повторить вопрос 1. Ожидаемо: ответ приходит (для сценария `openai` эта проверка неприменима).

## 5. Пункт 3: чат-ассистент подключён к сайту

1. На каждой из четырёх страниц в правом нижнем углу есть кнопка чата.
2. Нажать кнопку: открывается окно с приветствием ассистента Минвайл.
3. Написать «Привет», затем «Что такое Кубрик?». Ожидаемо: ответ про систему управления проектами и задачами; под ответом — похожие вопросы.
4. Нажать на один из похожих вопросов: он отправляется в чат, приходит ответ.
5. Перейти на другую страницу сайта и задать «А что делает в нём ИИ-секретарь?». Ожидаемо: ответ про запись совещаний и поручения.
6. На странице `/faq` ввести в поиск «заменить Zabbix». Ожидаемо: первым идёт вопрос про системные компоненты для импортозамещения.
7. Остановить сервер (`Ctrl+C`) и отправить сообщение в чат. Ожидаемо: сообщение о том, что ответ получить не удалось; страница не зависает.

## 7. Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `FAISS index or metadata not found` при запуске сервера | Не построен индекс: `python -m backend.build_index` |
| Ошибка о несовпадении модели индекса | В `.env` изменили модель: пересобрать индекс той же командой |
| Долгий первый запуск `build_index` | Скачивается модель; повторные запуски быстрые |
| Порт 8000 занят | Запустить с `--port 8001` и заменить порт в адресах; для `smoke_test.py` порт указывается параметром (см. `README.md`) |
| В Windows `curl` искажает русский текст | Задавать вопросы на странице `/faq` или запустить `python scripts/smoke_test.py` |
