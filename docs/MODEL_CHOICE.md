# Выбор модели FAQ-ассистента Минвайл

## Характеристики ПК, на котором измеряли

| Параметр | Значение |
|---|---|
| Компьютер | iMac (Mac16,3), Apple M4 |
| ОС | macOS 27.2.1, arm64 |
| Процессор | 10 ядер (4 производительных и 6 энергоэффективных) |
| GPU | 10-ядерный Apple M4, Metal |
| ОЗУ | 32 ГБ |
| Диск | около 404 ГБ свободно |
| Python | 3.11.15 |

ПК тянет и локальные эмбеддинги, и небольшую локальную LLM. Для этой сборки выбран облачный сценарий C по решению заказчика.

## Сценарий

Основной режим: `EMBEDDING_PROVIDER=openai`, `ANSWER_MODE=openai`.

- Эмбеддинги: `text-embedding-3-small` (1536 измерений). Веса на этот диск не скачиваются.
- Генерация: `gpt-4.1-mini`, `temperature=0`.
- Отказ вне базы решает код по порогу косинуса, а не модель.
- В коде остаются провайдеры `local` и `extractive`, чтобы переключить режим через `.env` без правки API.

Шорт-лист из трёх локальных моделей эмбеддингов не гоняли: сценарий C уже задаёт модель OpenAI. Локальный прогон имел бы смысл при выборе A или B.

## Измерения на `data/faq_eval.json`

Набор не меняли. Индекс: два вектора на запись (вопрос и вопрос+ответ), FAISS `IndexFlatIP` по нормализованным эмбеддингам, затем лёгкое лексическое переранжирование.

| Метрика | Значение |
|---|---|
| Recall@1 | 0,933 (28/30) |
| Recall@3 | 1,000 (30/30) |
| Верных отказов `out_of_scope` | 5/5 |
| Порог косинуса | 0,31 |
| Среднее время запроса (эмбеддинг + поиск) | 337 мс |
| Пик ОЗУ процесса оценки | 91 МБ |
| Размер модели на диске | не хранится (OpenAI API) |

Два промаха Recall@1: «берёте ли вы сайты и порталы на сопровождение» и «сколько обращений в час обрабатывает система». Оба попадают в тройку, поэтому Recall@3 полный.

Запросы о деньгах не содержат сумм: в базе нет цен, а генерации с суммами отсекаются правилом в коде.

Диалоги памяти: после вопроса о «Горизонте» реплика «А какие результаты?» даёт `faq-015` (76%); после вопроса о промышленном ИИ — `faq-037` (0,8%).

## Ограничения

- После первого запуска интернет нужен: и эмбеддинги, и ответы идут в OpenAI. Проверка «сервер без сети» из этапа 1 для сценария C не применяется.
- Нужен `OPENAI_API_KEY` в `.env`.
- Порог 0,31 подобран на этом проверочном наборе. Если база вырастет, порог нужно измерить заново.
